FAQ

Built to answer your technical questions.

What data does the API provide?

The response schema covers creator intelligence, wallet activity, token concentration, behavioral findings, source evidence and machine-readable data-quality fields. Availability depends on the individual token.

Can I use AHX with my existing trading bot?

Yes, via an HTTP JSON investigation endpoint. AHX provides information for your risk and research workflow; your application retains execution authority. Data quality and age should be evaluated for each requested token.

Must I reveal a wallet seed or private key?

Never. Do not enter wallet secrets into this site, chats, or agent-controlled pages. Review payment details and approve transactions directly in your wallet.
